# U净 开源极简客户端 —— 设计方案

目标：一个**无广告、无埋点、无定位采集**的 Android 客户端，覆盖「扫码 → 选模式 → 下单 → BLE 启动」全流程。

---

## 1. 与官方 APP 的差异

| 项 | 官方 APP | 本项目 |
|---|---|---|
| UI 框架 | Weex（Vue2）+ 热更新 | Jetpack Compose |
| 广告 | 有 | **无** |
| 埋点上报 | Bugly + 神策类 + 自定义 log | **无** |
| 定位 | 强制申请 | **不需要**（除非接口强校验） |
| 推送 | 友盟/极光 | **无** |
| 分享 | 微博/微信 SDK | **无** |
| 加固 | 360 加固 | 无（开源） |
| 体积 | ~100 MB | 目标 < 8 MB |
| 权限 | 一堆 | 仅 `BLUETOOTH_SCAN` / `BLUETOOTH_CONNECT` / `CAMERA` |

## 3. 数据流

```
①扫码
  qrCode → POST /devices/scanWasherCode → deviceId
      ↓
②查模式
  GET /app/washer/devices/program/info?deviceId=
  → deviceWashModel[], storeId, deviceTypeId, type
      ↓
③下单
  POST /orders/create {deviceId, deviceWashModelId, storeId, deviceTypeId, type, ...}
  → orderId
      ↓
④支付
  orderId → 支付渠道 → 轮询订单状态 (PAID=20)
      ↓
⑤取 macAddress
  GET /orders/{orderId}/detail?additional=price
  → macAddress, orderNo, deviceId     ← macAddress 来源（待实机确认）
      ↓
⑥BLE 启动
  连接 macAddress → 触发随机数 → 上报 → 取令 → 写包
```

### 4.3 帧编解码（`ble/FrameCodec.kt`）

```kotlin
data class Frame(
    val frameNum: Int, val total: Int,
    val pkgNum: Int, val pkgLen: Int,
    val payload: String, val raw: String
)

object FrameCodec {
    fun parse(hex: String): Frame? {
        val h = hex.replace(" ", "").uppercase()
        if (h.length < 8) return null
        return Frame(
            h.substring(0, 2).toInt(16),
            h.substring(2, 4).toInt(16),
            h.substring(4, 6).toInt(16),
            h.substring(6, 8).toInt(16),
            h.substring(8), h
        )
    }

    /** frameNum + total + xor(pkgNum) + sum(pkgLen) + ("00"|"01") */
    fun buildAck(frames: List<Frame>): ByteArray {
        if (frames.isEmpty()) return ByteArray(0)
        val xor = frames.fold(0) { acc, f -> acc xor f.pkgNum }
        val sum = frames.sumOf { it.pkgLen }
        val last = if (frames.size < frames[0].total) "01" else "00"
        return "%02X%02X%02X%02X%s".format(frames[0].frameNum, frames[0].total, xor, sum, last)
            .hexToBytes()
    }
}
```

### 4.4 启动状态机（`ble/WasherSession.kt`）

```kotlin
class WasherSession(
    private val ctx: Context,
    private val api: UjingApi,
    private val mac: String,
) {
    private val frames = mutableListOf<Frame>()
    private var curFrameNum: Int? = null
    private val assembled = CompletableDeferred<List<Frame>>()

    private val dataCb = object : BluetoothGattCallback() { /* ... 收包 → 组包 ... */ }

    suspend fun launch(command: String = "startWash") {
        connect(mac)
        notify(CypressUuids.DEVICE_APP_DATA)
        notify(CypressUuids.DEVICE_APP_ACK)

        // 1. 触发随机数
        write(CypressUuids.APP_DEVICE_DATA, CypressUuids.READ_RANDOM)
        val got = withTimeout(10_000) { assembled.await() }

        // 2. 上报云端
        api.bleDataReport(mac, got.map { it.raw })

        // 3. 回 ACK
        write(CypressUuids.APP_DEVICE_ACK, FrameCodec.buildAck(got))

        // 4. 取云端指令
        val pkgs = api.bleCommandAcquire(mac, command)

        // 5. 逐包写
        pkgs.forEach { item ->
            item.packages.forEach { p ->
                write(CypressUuids.APP_DEVICE_DATA, p.hexToBytes())
                delay(1000)
            }
        }

        // 6. 收响应 → ACK
        val resp = runCatching { withTimeout(10_000) { assembled.await() } }.getOrDefault(emptyList())
        if (resp.isNotEmpty()) write(CypressUuids.APP_DEVICE_ACK, FrameCodec.buildAck(resp))

        disconnect()
    }
}
```

## 6. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| UI | Jetpack Compose | 极简、无 XML 膨胀 |
| 网络 | OkHttp + kotlinx.serialization | 轻量，无 Retrofit 也可 |
| BLE | 原生 `BluetoothGatt` | 无第三方依赖 |
| 扫码 | CameraX + ML Kit Barcode | 或 ZXing 更小 |
| 存储 | DataStore (Preferences) | 只存 token |
| 构建 | Gradle KTS, minSdk 26 | 覆盖足够 |

## 7. 待实机确认（阻塞项）

| # | 项 | 影响 |
|---|---|---|
| 1 | `macAddress` 字段来源（`orders/{id}/detail` 还是 `program/info`） | 决定 ⑤ 步实现 |
| 2 | `ble/command/acquire` 真实响应结构 | 决定写包循环 |
| 3 | 设备是否校验 ACK 超时 | 决定是否需要严格 ACK |
| 4 | 指令帧可否重放 | 决定是否需每次取令 |
| 5 | 支付链路是否可绕过（是否必须官方支付） | 决定支付模块 |
| 6 | `createBLEDirectConnection` 原生行为（是否需 MAC 白名单） | 决定连接方式 |

抓包方法：Android 开发者选项 → 启用「蓝牙 HCI 信息收集日志」；HTTPS 用 mitmproxy + 证书固定绕过（若目标 APP 有 pinning）。
